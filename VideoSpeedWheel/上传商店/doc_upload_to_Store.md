# 中文
标题：视频倍速调节（滚轮+键盘）
摘要：轻量高效的视频倍速调节工具，支持鼠标滚轮/键盘快捷键，多平台个性化配置与速率记忆
说明（请着重说明该内容的用途以及用户为何应该安装它）：

还在反复点开播放器菜单调倍速？安装本扩展后，把鼠标移到倍速显示区域，滚轮上下即可微调速度——比原生菜单更快、更顺手。也支持 Win+Alt+↑/↓ 键盘快捷键，以及 Win+Alt+数字直接跳到指定倍速，学习、追剧、刷课都能按自己的节奏来。

【为什么值得安装】
• 操作极简：滚轮或快捷键即可调节，无需离开全屏、无需多次点击菜单
• 多平台适配：针对 B 站、YouTube、抖音、快手、小红书、X（Twitter）、Udemy 等站点优化，通用视频页也可使用
• 按站记忆：可为每个网站单独设置调节步长、最小/最大倍速，并记住上次播放速度，下次打开自动恢复
• 轻量无打扰：专注倍速这一件事，不注入多余界面，不影响页面原有体验

【使用方法】

▶ 第一步（必做）：安装或更新扩展后，请刷新正在观看的视频页面（F5），否则不会生效。

本扩展有两种工作模式，系统会自动判断，你无需手动切换：

━━ 模式 A：已适配站点（B 站、YouTube、抖音、快手、小红书、X、Udemy 等）━━
1. 打开视频并开始播放（暂停状态部分站点可能无倍速区域）
2. 在播放器控制栏找到「倍速」或「1.0x」等显示当前倍速的位置
3. 把鼠标移上去，停在倍速文字/按钮上（光标移上去即可，不用点击）
4. 滚轮向上 = 加快；滚轮向下 = 减慢（默认每次 ±0.1，可在弹窗修改）
5. 若滚轮没反应：确认鼠标确实悬停在倍速区域上，而不是画面中间；关闭遮挡播放器的弹窗/广告后再试

━━ 模式 B：通用模式（其他任意含视频的网页）━━
未单独适配的网站会自动进入通用模式，操作方式不同，请注意：
1. 打开页面并播放视频（页面上须有可见的 HTML5 视频）
2. 把鼠标移到视频画面的右侧边缘、垂直居中附近（画面右侧约 1/10 宽、高度中间区域）
3. 会出现黑色小标签，显示当前倍速（如「1.00x」）——这就是通用模式的调节入口
4. 鼠标停在该热区或黑色标签上，滚轮向上加快、向下减慢
5. 若看不到黑色标签：视频可能太小或被全屏/画中画遮挡；先退出全屏，或把鼠标在视频右缘上下缓慢移动找热区
6. 通用模式下键盘快捷键仍可用（见下方），会调节页面上所有检测到的视频

━━ 键盘快捷键（两种模式均可用）━━
• Win+Alt+↑：加快一档（步长与滚轮相同）
• Win+Alt+↓：减慢一档
• Win+Alt+数字：直接输入目标倍速。例如要 1.5 倍：按住 Win+Alt，依次按 1、.、5，约 1.5 秒内输完即生效；要 2 倍：按 2 即可
• 注意：须同时按住 Win 键与 Alt 键；若无效，检查是否被其他软件占用了 Win+Alt 组合键

━━ 点击扩展图标 · 个性化设置 ━━
1. 在要配置的视频页面，点击浏览器工具栏中的本扩展图标
2. 可设置：滚轮步长、最小/最大倍速、是否记忆上次倍速、默认倍速
3. 点「保存配置」后，建议刷新当前页面使设置完全生效
4. 若某站不想用本扩展：勾选「禁止在此网站运行」后刷新页面

━━ 还是不行？快速自查 ━━
□ 是否已刷新视频页？　□ 是否误关了本站扩展？　□ 倍速是否被站点本身限制（如抖音最高约 3～4 倍）？
□ 通用模式：鼠标是否在视频右侧热区？　□ 专用模式：鼠标是否在播放器自带的倍速显示上？

# English
Title: Video Speed Control (Wheel + Keyboard)
Summary: Lightweight video speed control with mouse wheel and keyboard shortcuts, per-site settings, and speed memory
Description (explain what it does and why users should install it):

Tired of opening the player menu every time you want to change playback speed? With this extension, hover over the speed display on the video page and scroll the mouse wheel to fine-tune—faster and smoother than the built-in controls. Keyboard shortcuts are supported too: Win+Alt+↑/↓ for step adjustments, and Win+Alt+number to jump to a specific speed. Perfect for courses, tutorials, and binge-watching at your own pace.

【Why install】
• Simple controls: adjust speed with the wheel or shortcuts—no leaving fullscreen, no repeated menu clicks
• Multi-platform: optimized for Bilibili, YouTube, Douyin, Kuaishou, Xiaohongshu, X (Twitter), Udemy, and generic video pages
• Per-site memory: set step size, min/max speed, and remember your last rate for each site—restored automatically next visit
• Lightweight: focused on speed control only, no extra UI clutter, minimal impact on the page

【How to use】

▶ Step 1 (required): After installing or updating, refresh the video tab (F5) or the extension will not run.

The extension picks a mode automatically—you do not switch manually:

━━ Mode A: Supported sites (Bilibili, YouTube, Douyin, Kuaishou, Xiaohongshu, X, Udemy, etc.) ━━
1. Open a video and start playback
2. Find the player’s speed display (e.g. “1.0x” or a “Speed” control)
3. Hover the mouse over that label/button (no click needed)
4. Scroll up = faster; scroll down = slower (default step 0.1, configurable in the popup)
5. No response? Make sure the cursor is on the speed UI, not the middle of the video; dismiss overlays/ads blocking the player

━━ Mode B: General mode (any other page with HTML5 video) ━━
1. Play a visible HTML5 video on the page
2. Move the mouse to the right edge of the video, vertically near the center (~right 10%, middle height)
3. A small black badge appears (e.g. “1.00x”)—this is the control in general mode
4. Keep the pointer in that hot zone or on the badge; scroll up/down to change speed
5. Badge missing? Video may be too small or in fullscreen/PiP—exit fullscreen or sweep along the right edge
6. Keyboard shortcuts below still work and affect all videos detected on the page

━━ Keyboard shortcuts (both modes) ━━
• Win+Alt+↑: faster by one step
• Win+Alt+↓: slower by one step
• Win+Alt+digits: set speed directly. For 1.5x: hold Win+Alt, press 1, ., 5 within ~1.5s; for 2x: press 2
• Hold both Win and Alt; if nothing happens, another app may be using Win+Alt

━━ Extension popup · per-site settings ━━
1. On the video tab, click the extension icon
2. Set step size, min/max speed, speed memory, default speed
3. Click Save, then refresh the tab for a clean apply
4. To disable on a site: check “Disable on this site” and refresh

━━ Quick checklist ━━
□ Refreshed the tab?　□ Extension enabled for this site?　□ Site cap (e.g. Douyin ~3–4x max)?
□ General mode: pointer in the right-edge hot zone?　□ Supported site: pointer on native speed UI?

Ideal for anyone who watches online courses, tutorials, or long-form video—spend time on content, not fighting the player menu.

# Privacy & permissions (English)

**Single purpose description (≤1000 chars):**

This extension has one purpose: adjust HTML5 video playback speed on web pages using the mouse wheel or keyboard shortcuts. It does not collect user data, alter unrelated page content, or provide features beyond speed control. Users can fine-tune or set playback speed on supported video sites (e.g. Bilibili, YouTube) and save per-site preferences (step size, min/max speed, speed memory).

**Justification for `storage`:**

The `storage` permission is used only to save video speed settings locally on the user’s device: per-site step size, min/max speed, speed-memory toggle, last playback rate, and a list of sites where the user chose “Disable on this site.” All data stays in `chrome.storage.local`; nothing is uploaded or shared with third parties. This permission is required for per-site preferences and the popup configuration UI.

**Justification for `activeTab`:**

`activeTab` is used only when the user clicks the extension icon to open the popup. It reads the active tab’s URL to detect supported video sites and load or save that site’s speed settings. The extension does not scan tabs in the background or access tab content when the popup is closed, and URLs are not sent to external servers.

**Justification for host permissions (`<all_urls>` in content_scripts):**

Host access injects a content script on pages that may contain video, solely to control HTML5 playback speed: find `<video>` and the player’s speed UI, listen for wheel/keyboard input, and apply locally stored speed settings. Video sites use many different domains, so patterns cannot be fully enumerated in the manifest; `<all_urls>` is used instead. Users can disable the extension per site in the popup. The extension does not read passwords/forms, inject ads, or make network requests unrelated to speed control.

**Are you using remote code?**

No. All extension logic is bundled inside the package (WXT build). No JavaScript or WebAssembly is loaded or executed from remote servers; no executable code is fetched from external URLs.
